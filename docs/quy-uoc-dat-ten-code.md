# Quy ước đặt tên trong mã nguồn

- Tên do dự án tự định nghĩa dùng tiếng Việt không dấu.
- Biến, hàm và thuộc tính dùng `camelCase`; component và kiểu tự định nghĩa dùng `PascalCase`; lớp CSS và biến CSS dùng `kebab-case`.
- Giữ nguyên cú pháp JavaScript, API trình duyệt, React, Express, driver/ORM, cú pháp SQL và các tên do thư viện quy định. Ví dụ: `useState`, `children`, `className`, `onClick`, `Router`, `router`, `req`, `res`, `next`, `query`, `execute`.
- Giữ nguyên tên file, URL/route, khóa JSON/API và tên bảng/cột trong database vì đó là các giao kèo hoặc đường dẫn bên ngoài.
- Khi tên tiếng Việt theo nghĩa đen nghe gượng, chọn cách diễn đạt tự nhiên theo hành động hoặc nghiệp vụ. Ví dụ: `dichVuKhachHang`, `timKhachHangTheoSoDienThoai`, `dinhTuyenKhachHang`.
